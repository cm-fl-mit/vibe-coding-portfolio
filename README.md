# vibe-coding-portfolio

##In Fall 2025, I was a Teaching Fellow at Harvard's Graduate School of Education. The course, "Vibe Coding," explored the intersection of AI-assisted coding tools and constructionist learning, investigating how these tools can support creative, meaningful learning through making. 

##As part of co-teaching the class, I built demo projects exploring practical applications, game design, and physical computing with AI assistance. These projects, and an example portfolio I made using my own work and reflections, live in this repo.
